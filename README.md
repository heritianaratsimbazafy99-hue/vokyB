# VokyB Landing Page

Landing page responsive et visuelle pour la marque de nouilles instantanées VokyB.

## Structure

- `index.html` : page principale
- `styles.css` : direction artistique, responsive et animations
- `script.js` : navigation mobile, interaction des saveurs et révélations au scroll
- `assets/` : logo, produits, visuels éditoriaux et images générées

## Lancer en local

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

Puis ouvrir `http://127.0.0.1:8000/`.
